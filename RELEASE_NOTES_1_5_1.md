# Release 1.5.1 — Biblioteca Corporativa com sumário automático

## Mudanças

- Remove o campo visível `Conteúdo do documento para uso da IA`.
- Gera sumário técnico interno automaticamente ao carregar documento.
- Não exibe o sumário para o usuário da empresa.
- Alinha os botões de PDI Relacional e Corporativo.
- Adiciona descrição e exemplo em cada campo do Contexto operacional do PDI.

## SQL

Não há SQL obrigatório novo para quem já aplicou a 1.5.0.
