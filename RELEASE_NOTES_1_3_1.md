# Release 1.3.1 — Ajustes Sandbox e Relatório Lifenergy V1.0

## Ajustes do formulário público

- Tela de boas-vindas informa o tempo estimado de 10 minutos por fractal ou atividade.
- A tela 2 passa a exibir o texto institucional/orientativo definido pelo usuário.
- A tela de resumo final consolidado foi removida.
- O botão "Concluir Avaliação" agora bloqueia múltiplos cliques e exibe "Enviando avaliação...".

## Ajustes no Painel → Avaliados

- "Abrir link" e "Copiar link" aparecem apenas para links pendentes.
- Após conclusão da avaliação, as opções de link desaparecem.
- O botão "Gerar Relatório DOCX" foi renomeado para "Gerar relatório".
- O botão "Gerar relatório" agora possui proteção contra múltiplos cliques.

## Ajustes em Laudos/Exportações

- A tela "Laudos" deixa de aparecer para usuários clientes.
- A tela "Laudos" passa a aparecer apenas para o super usuário.
- A exportação foi mantida.
- A exportação agora pode ser filtrada por empresa, avaliado e período.

## Ajustes no Relatório Lifenergy V1.0

- O prompt interno e a estrutura do DOCX foram ajustados para seguir o modelo anexado pelo usuário.
- O relatório passa a seguir a estrutura:
  1. Identificação
  2. Registro de Aplicação
  3. Registro de Dados – Resultado
  4. Síntese dos padrões psicológicos de comportamento recorrentes
  5. Recomendações para desenvolvimento de habilidades
  6. Categorização dos padrões de comportamento (0 a 100%)
- Cada fractal agora possui tabela própria, interpretação e sugestões de desenvolvimento.
- Removida a seção de Prioridades Terapêuticas nesta versão, porque ela não aparece no modelo anexado.
