# Release 1.5.3

Ajusta a tela PDI, a Biblioteca Corporativa e o formato do PDI Corporativo.

## Principais mudanças

- Novo quadro PDI no Painel.
- Documentos corporativos com Editar, Download e Atualizar.
- Remoção da coluna Status IA.
- Download do arquivo original do documento corporativo.
- Aviso de necessidade de regerar PDI Corporativo após atualização de documentos.
- Opção Gerar novo PDI Corporativo quando o contexto corporativo mudou.
- PDI Corporativo com linguagem e layout mais alinhados ao modelo revisado.
